Como Acessar o Módulo de Ponto

Início

Existem três formas de acessar a folha de ponto no sistema:

Página Inicial

Na tela principal do sistema, clique no card Módulo I — RH e selecione Folha de Ponto na lista de funcionalidades.

Menu Lateral

No menu à esquerda, expanda a seção Menu Principal e clique em Cadastro para gerenciar funcionários, ou em Abrir Editor para lançar horários.

Acesso rápido: Utilize o campo de busca de funcionários na tela principal do módulo de ponto para localizar rapidamente um colaborador.

Importante: Para acessar o módulo de ponto, você precisa estar logado com um perfil que tenha permissões de Usuário ou Administrador. Perfis Visualizador podem apenas consultar dados, sem editar.

Tela Principal da Folha de Ponto

Visão Geral

A tela de controle de ponto é composta por 3 áreas principais:

Área do Funcionário

Exibe o nome, empresa, matrícula/CPF e foto do colaborador selecionado. Permite filtrar por empresa para facilitar a busca.

Seleção de Período

Permite escolher o mês e ano desejados para visualização e edição da folha de ponto.

Tabela de Ponto

Exibe todos os dias do mês com os campos: Entrada 1, Saída 1, Entrada 2, Saída 2, totais parciais e hora extra calculada automaticamente.

Exemplo da tela: Tabela com 31 linhas (dias do mês), colunas para os 2 turnos e totais.

A tela exibe automaticamente os dados salvos para o funcionário selecionado.

Totalizadores: Ao final da tabela, um resumo exibe o total de horas extras do mês, dias com hora extra e o saldo acumulado.

Cadastro de Funcionários

Gerenciamento

Para começar a usar o sistema de ponto, é necessário cadastrar os funcionários.

📋 Como cadastrar:

1
Acesse o menu lateral e clique em Cadastro.
2
Preencha os campos obrigatórios: Nome Completo e Unidade (empresa).
3
Opcionalmente, adicione CPF, Data de Admissão, Validade do ASO e Aniversário.
4
Clique na área de foto para anexar uma imagem do funcionário (máx. 2MB).
5
Clique em Salvar Cadastro.
Dados persistidos: Todos os funcionários são salvos no Supabase, garantindo que os dados estejam disponíveis em qualquer dispositivo.
Campo Obrigatório Descrição
Nome Completo✅ SimNome do colaborador
Unidade✅ SimEmpresa onde trabalha (Spoleto, A2B, Acço, Copaenergia, INSS, Qnutri)
CPF❌ NãoNúmero do CPF (para identificação)
Data Admissão❌ NãoData de contratação
Validade ASO❌ NãoData de validade do Atestado de Saúde Ocupacional
Aniversário❌ NãoData de nascimento do funcionário
Foto❌ NãoImagem do funcionário (JPEG, PNG, WEBP)

Selecionar Funcionário

Busca

Após cadastrar os funcionários, você pode selecioná-los de 2 formas:

Campo de Busca

Digite o nome do funcionário no campo de busca. O sistema sugere nomes automaticamente (autocomplete).

Ao selecionar, a tabela é preenchida automaticamente.

Filtro por Empresa

Use o filtro de unidade para restringir a lista de funcionários, facilitando a localização.

Foto do funcionário: Quando um funcionário é selecionado, sua foto e informações são exibidas no painel lateral.

Dica: Ao selecionar um funcionário, o sistema carrega automaticamente os dados de ponto salvos para o mês/ano atual.

Preencher Horários

Lançamento

Os horários de ponto podem ser lançados de 3 formas:

Manual Direto

Clique nos campos de hora na tabela principal e digite o horário (formato HH:MM).

Todos os campos são editáveis para usuários com permissão.

Editor de Ponto

Acesse o Editor de Ponto para visualizar e editar todos os dias do mês em uma interface otimizada.

OCR (Reconhecimento)

Carregue uma imagem do cartão de ponto e use o OCR para ler automaticamente os horários.

⏱️ Cálculos Automáticos

Ao preencher os horários, o sistema calcula automaticamente:

  • Total 1º Turno: Diferença entre Entrada 1 e Saída 1
  • Total 2º Turno: Diferença entre Entrada 2 e Saída 2
  • Total Geral: Soma dos dois turnos
  • Hora Extra: Total Geral excedente à jornada padrão de 08:00
Atenção: Horários inválidos (ex: entrada maior que saída) são marcados como erro e listados no módulo Erros de Marcação.

Editor de Ponto

Ferramenta

O Editor de Ponto é uma ferramenta avançada para lançamento e correção de horários.

📌 Como acessar:

No menu lateral, clique em Abrir Editor. (O funcionário deve estar selecionado previamente)

🛠️ Funcionalidades do Editor:

Anexar Cartão

Carregue uma imagem do cartão de ponto para referência visual durante a edição.

OCR

Execute o reconhecimento óptico de caracteres para extrair horários da imagem anexada.

Preencher Vazios

Preenche automaticamente os campos vazios com horários padrão (08:00, 12:00, 13:00, 17:00).

Zoom

Controles de zoom para visualizar detalhes da imagem do cartão.

Salvamento: Clique em Aplicar Dados para salvar as alterações no Supabase.

Dica de cores:

  • Verde — Campo preenchido pelo OCR
  • Laranja — Campo preenchido manualmente
  • Vermelho — Campo com erro (verificar)

Ajustes de Marcações

Correções

A ferramenta Ajustes de Marcações permite corrigir horários de um dia específico.

📌 Como usar:

1
No menu lateral, clique em Ajustes de Marcações.
2
Selecione o funcionário e a data desejada.
3
Edite os horários diretamente nos campos exibidos.
4
Clique em Salvar Ajustes para persistir as alterações.
Integração: Os ajustes salvos são automaticamente refletidos na tabela principal da folha de ponto.

OCR e Anexos de Cartões

Automação

O sistema utiliza reconhecimento óptico de caracteres (OCR) para ler horários de imagens de cartões de ponto.

📌 Como usar o OCR:

1
Abra o Editor de Ponto.
2
Clique na área de upload para selecionar uma imagem (JPG, PNG, WEBP - máx. 5MB).
3
A imagem será exibida no visualizador do editor.
4
Clique em Tentar OCR novamente para processar a imagem.
5
Os horários reconhecidos serão preenchidos nos campos correspondentes (marcados em verde).
Armazenamento: As imagens dos cartões são salvas no Supabase, permitindo consulta e download posterior.
Dica: Para melhores resultados de OCR, utilize imagens nítidas, bem iluminadas e com boa resolução.

Funcionalidades adicionais:

  • Baixar anexo — Faz o download da imagem do cartão salva.
  • Remover imagem — Remove a imagem da visualização.
  • Zoom — Amplia a imagem para melhor visualização.

Relatórios e Cartão de Ponto

Documentação

O sistema oferece 2 tipos de relatórios em PDF para documentação e controle.

Relatório de Ponto

Gera um PDF com a tabela completa de horários do funcionário, incluindo totais e horas extras.

Filtros: Empresa, Funcionário, Mês

Ficha Cadastral

Gera um PDF com os dados cadastrais do funcionário, incluindo foto e informações pessoais.

Filtros: Empresa, Funcionário

📌 Como gerar relatórios:

1
No menu lateral, clique em Relatórios.
2
Escolha entre Ponto por Funcionário ou Ficha Cadastral.
3
Aplique os filtros desejados (empresa, funcionário, mês).
4
Clique em Gerar PDF.

🪪 Cartão de Ponto Visual

O Cartão de Ponto (menu lateral → Visualizar Cartão de Ponto) exibe:

  • Dados do funcionário com foto
  • Tabela com todos os dias do mês e horários
  • Resumo com dias trabalhados, total de horas e horas extras
  • Visualização do cartão anexado (se houver)

Perguntas Frequentes

Dúvidas
1
Como faço para ver a folha de ponto de um funcionário?

Digite o nome do funcionário no campo de busca principal. A tabela será carregada automaticamente com os dados do mês selecionado.

2
Onde são salvos os dados da folha de ponto?

Os dados são salvos no Supabase (banco de dados em nuvem). Além disso, uma cópia local é mantida no localStorage do navegador como cache.

3
Como corrigir um horário que foi preenchido errado?

Você pode corrigir diretamente na tabela principal, no Editor de Ponto ou na ferramenta Ajustes de Marcações. Lembre-se de salvar as alterações.

4
O que são os campos marcados em vermelho?

Campos em vermelho indicam erros de marcação, como entrada sem saída, saída sem entrada ou horário inválido (entrada > saída).

5
Como funciona o cálculo de horas extras?

O sistema calcula a diferença entre o Total Geral do dia e a jornada padrão de 8 horas. O resultado é exibido na coluna "Hora Extra".

6
Posso acessar o sistema pelo celular?

Sim! O sistema é totalmente responsivo e adaptado para smartphones e tablets, com menus colapsáveis e botões otimizados para toque.

7
O que fazer se o OCR não reconhecer os horários corretamente?

Verifique se a imagem está nítida e bem iluminada. Você pode ajustar manualmente os horários após o OCR, ou usar o preenchimento automático de vazios.

8
Como excluir um funcionário?

No módulo Cadastro, localize o funcionário na lista e clique no ícone ao lado do nome. Confirme a exclusão.
